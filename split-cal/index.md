# Split Cal

Welcome to the Split Cal homepage.

Do you use Splitwise to track reoccuring monthly expenses, such as with roommates or significant others? Are you tired of running out of Splitwise transactions and having to wait after only a few items per month?

This app aims to solve that problem by automating the creation of your monthly expenses, 1 month in advance.

Define your expenses in Split-Cal. Set up a reoccuring task on your computer to run it monthly. It will look ahead for 1 month and create any needed expenses. You can go back and edit the amounts or splits later, if needed. If you hit your expense limit, simply run the tool again the next day and it will pick up where it left off, skipping any pre-existing transactions. (Note: date, name and amount must still match to skip.)

This app is not affiliated with Splitwise, it is simply an independent client that uses the SDK. Please use this app for recurring transactions only, not as a general workaround Splitwise ads. We hope you will consider a Splitwise Pro membership.
